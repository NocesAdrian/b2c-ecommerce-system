# B2C E-Commerce System

A simple B2C e-commerce system for online merchandise sales.

## Features

* Product management
* User management and authentication
* Shopping cart management
* Order management

## Stack

* PHP
* MySQL
* HTML
* CSS
* JavaScript

## Database

Database name: `b2c_ecommerce`

## Setup

1. Clone this repository.
2. Create the `b2c_ecommerce` database.
3. Import the database schema.
4. Configure the database connection.
5. Run the application using your local PHP server.
